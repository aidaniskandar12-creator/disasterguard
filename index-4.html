Live (real-time):

  • Earthquakes — USGS all-day M4.5+ feed (refreshes every 5 min)
  • Weather / rain / wind — Open-Meteo forecast API
  • Air quality at your location — Open-Meteo Air Quality (US AQI, PM2.5)
  • Rain radar — RainViewer public tiles

Curated / community:

  • Floods, typhoons, tsunamis, hail, forest fires, city AQI pins — curated baseline points you can fully edit in this panel. Update them here when real events change.
  • User reports via the Report button are added locally in-session.

There is no free global live flood API with the same reliability as USGS quakes. Use Edit Alerts + Save to browser to keep flood/fire data current for demos and competitions.

Alert Hub (centralized): Dev → Alert Hub. Modes: Local, Broadcast (tabs), Poll URL, Firebase RTDB. Reports and “Publish simulation” go through the hub. Nearby clients with notifications enabled get a browser notification. True lock-screen push still needs Web Push (FCM/VAPID) on HTTPS.
